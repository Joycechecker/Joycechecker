# 工作台清晰化设计

日期：2026-03-11

## 参考

参考页：[一伴 AI 编辑器介绍](https://yiban.io/blog/30811)

这类编辑器最值得借的不是视觉细节，而是工作流分层很清楚：

1. 先输入主题和素材。
2. 明确有一个“结果区”承接生成结果。
3. 预览、复制、导出围绕结果区展开，而不是散落在页面不同位置。

## 本次调整

1. 强化右侧结果区：生成完成后自动跳到右侧。
2. 把“复制正文 / 复制 HTML / 导出 HTML”集中到结果区头部。
3. 未生成前，不再让默认 mock 稿伪装成当前结果。
4. 用户改了前置 brief 后，会标记当前稿为“上一轮生成稿”，提醒重新生成。

## 目的

让用户一眼知道：

- 输入在左边
- 结果在右边
- 输出按钮就在结果上方

这样比把编辑、配图、导出动作四处分散更接近真实内容生产工作台。
