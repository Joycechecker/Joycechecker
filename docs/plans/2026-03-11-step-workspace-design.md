# 四步工作台设计

日期：2026-03-11

## 问题

左侧输入区是连续长页面，用户要在“账号信息、内容要求、当前稿、配图”之间来回翻找，滚动成本很高。

## 方案

把左侧改成四步工作台，一次只展示一个阶段：

1. `账号与选题`
2. `成稿要求`
3. `当前稿`
4. `图片处理`

右侧结果区保持固定职责：承接生成结果、预览和输出。

## 交互规则

- 默认从“账号与选题”开始。
- 做完选题分析后，自动切到“成稿要求”。
- 成稿生成或优化后，自动切到“当前稿”。
- “当前稿”“图片处理”在没有生成真实稿之前保持锁定。

## 目的

让用户的认知更像使用真正的编辑器，而不是在一张超长表单里来回滚动找模块。
