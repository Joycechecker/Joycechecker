# Studio 三栏工作台外壳

## 目标

把当前 Studio 从“长页面堆表单”改成更清楚的内容工作台：

- 左侧固定步骤导航
- 中间只处理当前步骤
- 右侧固定公众号预览与导出

## 参考方向

借鉴内容编辑器 SaaS 的三栏骨架，但不照搬博客 CMS：

- 左栏负责“我在哪一步”
- 中栏负责“我现在正在做什么”
- 右栏负责“结果长什么样、怎么导出”

## 保留原则

- 账号与选题 / 成稿要求 / 当前稿 / 图片处理 这四步不变
- 现有 API、状态字段、图片上传和草稿暂存逻辑不变
- 只重做外层布局和信息层级

## 具体调整

- 去掉顶部大段 hero 说明，避免占据第一屏
- 把步骤导航收进左侧竖向侧栏
- 中间主区增加：
  - 当前步骤标题
  - 生成按钮或信息补齐卡
  - 当前上下文标签
- 右侧继续固定手机预览和输出动作

## 结果

用户进入页面后，不再先看到一大段介绍，而是直接看到：

1. 左边步骤
2. 中间当前任务
3. 右边预览结果

这更接近成熟工作台，也更适合后续继续补登录、额度、支付和历史记录。
