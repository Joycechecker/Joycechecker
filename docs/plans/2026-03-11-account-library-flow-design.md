# 公众号号库与本次任务拆分

## 目标

把“新号 / 老号”的判断从每次生成前都重复回答，改成一次建档、后续复用的工作流。

## 设计

- `账号档案` 保存长期稳定信息：
  - 公众号名称
  - 账号目标
  - 长期内容方向
  - 可复用的历史文章链接 / 标题
- `本次任务` 只保存这次生成需要补充的内容：
  - 本次选题
  - 推广对象
  - 目标人群
  - 内容要点
  - 内容目标
  - 人工意见
  - 本次新增规划方向 / 新栏目尝试

## 当前实现

- 前端在浏览器 `localStorage` 里维护一个本地“我的号库”
- 首次建档后，账号会在选题分析或文章生成成功后自动加入号库
- 用户也可以手动点击“保存到我的号库”或“更新账号档案”
- 再次进入 Studio 时，默认加载最近使用的账号档案
- 已有账号本次如果想试新方向，可用 `directionUpdate` 告诉 AI 输出桥接式选题，而不是整体改号

## 后续

- 接登录后把本地号库迁移到用户维度存储
- 给号库加最近生成记录和最近使用选题
- 支持账号归档、重命名、删除
