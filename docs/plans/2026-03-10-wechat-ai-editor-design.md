# 微信公众号 AI 排版工作台设计

## 目标

做一个首版可运行的 Web App，让内容团队从一个 brief 出发，快速得到公众号文章成稿和配图建议，并在同一界面完成预览与导出。

## 方案选择

- 不采用纯前端方案，因为真实 AI key 不应暴露在浏览器。
- 不采用前后端分离首版，因为当前仓库为空，先把产品路径跑通更重要。
- 采用 Next.js 全栈方案：前端负责 brief、编辑、预览；服务端负责调用 AI 文案和图片接口。

## 首版范围

- 输入表单：主题、品牌、人群、目标、风格、重点信息、是否出图
- 文案输出：标题、摘要、导语、章节正文、强调语、结尾 CTA
- 图片输出：封面图提示词、段落配图提示词、按需生成实际图片
- 成品预览：接近公众号阅读样式的移动端页面
- 导出：生成单文件 HTML

## 技术设计

- UI：React Client Component 管理 brief、结果、生成状态和导出
- 文案生成：调用 OpenAI Responses API；若未配置 key，回退 mock
- 图片生成：调用 OpenAI Images API；若未配置 key，回退 SVG 占位图
- 数据结构：统一 `GeneratedArticle` 类型，便于预览和导出复用
- 导出：服务端/客户端共享 HTML 渲染器，保证预览与导出风格一致

## 风险与处理

- 模型输出不稳定：通过固定 JSON 结构提示词 + 服务端标准化处理降低风险
- 图片成本和时延：首版默认只自动生成封面，其余配图按需触发
- 无 key 场景体验差：提供 mock 文案和占位图，让产品流程可先演示
