# 老公众号半自动提炼增强设计

日期：2026-03-11

## 目标

把老公众号分析从“只靠用户补充信息推断”升级成“优先使用真实历史线索，再由 AI 提炼内容方向”。用户仍然可以只输入公众号名开始，但系统会在服务端尽量先补到真实文章候选；如果外部搜索没有配置或没有结果，流程不能中断。

## 方案

1. 在服务端新增腾讯联网搜索适配层。
2. 老号分析时，若已配置腾讯搜索凭证且用户填写了公众号名，则先按公众号名检索 `mp.weixin.qq.com` 的候选文章。
3. 搜索结果不直接信任，而是再抓取候选微信文章页，提取标题、账号名、摘要等元数据。
4. 把“腾讯搜索结果 + 用户手动贴的文章链接 + 手动补的历史标题”合并成统一的历史线索集合。
5. 选题分析提示词优先使用这些历史线索；若没有真实线索，才退回账号名与定位推断。

## 设计原则

- 静默增强：外部搜索不可用时不报错中断，自动回退到原来的半自动流程。
- 证据优先：真实抓到的历史线索优先级高于纯推断。
- 前端不暴露密钥：腾讯搜索只运行在服务端。
- 去重：同一篇文章被搜索命中且又被用户手动粘贴时，只保留信息更完整的一份。

## 验证

- 无腾讯凭证时，老号分析仍可正常返回。
- 有腾讯凭证时，按公众号名能补充至少一批候选历史线索。
- `npm run lint` 和 `npm run build` 均需通过。
