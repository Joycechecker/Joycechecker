# Consumer System 培训图设计

## 目标

修复原图中连线穿过中心文案、层级不稳、文字不清的问题，重做成一张适合培训文件使用的消费者系统示意图。

## 方案

- 使用中心枢纽 + 四象限卡片的结构，强调“核心购买者”是家庭决策中心。
- 四条连接线改为向外发散的弧线，不再穿过中心圆形文字。
- 保留紫色体系，但降低背景和卡片饱和度，让投屏和打印更清楚。
- 卡片文案按两行拆分，避免长句挤压。
